Raccourcis

Tracer : clic = ajouter un point · Entrée, double-clic ou clic sur le 1er point = fermer · Retour = point précédent · Échap = annuler
Éditer : glisser un polygone = le déplacer en entier (Maj + glisser = tous les polygones de l'image) · glisser un sommet · clic sur un côté = nouveau sommet · double-clic ou Suppr = supprimer le sommet · flèches = déplacer de 0,5 px (Maj = 5 px)
Vue : molette = zoom · Espace + glisser, ou clic droit/milieu = déplacer · 0 = ajuster
Ctrl+Z / Ctrl+Y = annuler / rétablir
